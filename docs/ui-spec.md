# WinHappens · Live Duel — ТЗ на реализацию (для Claude Code)

Источник дизайна: `Live Duel.dc.html`, блоки **5a** (итоговый прототип iPhone), **5b** (экран с подписями), **4b** (чек-лист), **4c** (десктоп). Более ранние блоки (1–3) — история итераций, не реализовывать.

Цель: воспроизвести мобильный (390×844) и десктопный (1440×900) игровой экран «Чёт/Нечёт 1×1 с живым крупье», онбординг, видео-обучение и режим «Крупье отвечает взаимностью».

---

## 1. Стек и общие правила

- React 18 + TypeScript, Vite. Стили — CSS Modules или Tailwind (на выбор), без UI-китов.
- Состояние игры — один стор (Zustand или `useReducer` + Context). Видео — `<video>`-заглушки (на старте: градиент + штриховка + подпись «видео-кружок»).
- Мобильная вёрстка — эталон 390×844 (iPhone 14/15). На ширинах 360–430 тянуть по ширине, высота — flex.
- Все анимации — CSS transitions; easing: `cubic-bezier(.3,1.4,.5,1)` («выдвижение»/пружина), `cubic-bezier(.2,.8,.2,1)` (карусель).
- Язык интерфейса — русский.

### 3.1 Stage (сцена с видео-кружками)
- Фон: `radial-gradient(circle at 50% 42%, {dealer.tint}55, transparent 62%)` поверх `bg/app`; плавная смена при смене крупье (transition background .35s).
- Слева сверху: пилюля `LIVE · {scene}` (красная точка 8px), фон `#000000AA`, h28.
- Справа сверху: пилюля таймера `0:{sec}` (JetBrains Mono, цвет `#4F8BFF` когда идёт приём ставок, белый — когда ставки закрыты).
- По центру сверху (top 46): подсказка `← свайп · {листай крупье | в игре столов: N} →`, 11px, `text-secondary`.
- Кнопка «?» — справа, top 96 (от верха экрана), 32×32 круг, `#FFFFFF14`, обводка `#FFFFFF26` → запускает обучение.
- Стрелки ‹ › — круги 40px по краям сцены по вертикали 47%.
- Надпись раунда (caption) — по центру внизу сцены, bottom 12.

#### Карусель кружков
- Показывать текущего крупье и по 2 соседа (offset −2…+2, по кругу).
- Mobile: центр 236px (в режиме взаимности 184px), соседи ±1 — 110px (92px), шаг по X 170px (150px). Opacity: центр 1, ±1 — .55, ±2 — .3, занятая — .25.
- Desktop: центр 360px, ±1 — 190px, ±2 — 130px, шаг 330px (+40 для ±2).
- Внутри кружка: видео (object-fit: cover, круглая маска). Под кружком имя (центр: жёлтый не нужен — белый/`#FFE14D` допустимо), для центра подпись: `{name} · {count}/3 до взаимности` или `{name} · взаимность открыта`.
- **Белое кольцо прогресса** вокруг центрального кружка: SVG circle r=48 (viewBox 100), отступ 8px от кружка, трек `#FFFFFF22` 2px, прогресс `#FFFFFF` 3px, `stroke-dasharray = count/3 × 301.6`, transition .6s. При заполнении — `filter: drop-shadow(0 0 6px #fff) drop-shadow(0 0 14px #ffffffaa)`.
- Бейдж на соседних кружках (правый верх): ● жёлтый `#FFE14D` — раунд идёт; `+N` зелёный — выигрыш; `−N` красный — проигрыш.
- Жесты: свайп по сцене (pointerdown/pointerup, порог 40px) — prev/next, пропуская занятых. Тап по соседнему кружку — выбрать его. Тап по центральному (если это не свайп, |dx|<8) — **полноэкранное видео**.

### 3.2 DuelStrip
`[кружок 26px #00C853 с твоим числом или «?»] Вы · ЧЁТ — {mid} — НЕЧЁТ · {dealer} [кружок #FF4D6A с числом крупье или «?»]`
`mid`: `VS` (серый) до раскрытия; после — `{sum} · ЧЁТ|НЕЧЁТ` (цвет even/odd).

### 3.3 NumberBoard
- 10 плиток 0–9. Фон `#FFFFFF12`, обводка `1px #FFFFFF1F`; цифра 24px Mono, **цвет цифры = even/odd**.
- Выбрана: фон `#FFF`, обводка `2px #FFF`.
- Подписи «ЧЁТ/НЕЧЁТ» под цифрой — **только во время онбординга**, в игре скрыты.
- Неактивна (ставка сделана): opacity .35 у всех, кроме выбранной.
- **После подтверждения ставки**: цифра уменьшается до 13px и уходит в правый верхний угол плитки (absolute right 7 top 6), в центр плитки ложится фишка 34px с номиналом.

### 3.4 Фишка (компонент Chip)
- Круг; край: `repeating-conic-gradient({color} 0 30deg, #F4F1EA 30deg 45deg)`; внутренний круг (inset 14%) — сплошной цвет + `1.5px dashed #FFFFFFB3`; номинал белым 800.
- Тень: `0 3px 0 #00000088, 0 6px 12px #0006`.
- Выбрана: `box-shadow: 0 0 0 2px #FFF` + `translateY(-6px)`.
- Размеры: ряд — 44px (mobile) / 46px (desktop); на поле — 34px (mobile) / 56px (desktop).

### 3.5 Перелёт фишки
При подтверждении ставки: измерить rect выбранной фишки в ряду и плитки выбранного числа (относительно экрана), отрисовать «летящую» фишку absolute в позиции фишки ряда (transition none), через 2 rAF переместить в центр плитки (`left/top/width/height`, `.6s cubic-bezier(.3,1.25,.5,1)`). Фишка остаётся на плитке до конца раунда. Если измерить не удалось — показать статичную фишку на плитке.

### 3.6 BottomPanel
**Обычный режим — ChipsRow:** 5 фишек, справа колонка `Ставка {N}` / `Выигрыш {win}` (white-space: nowrap, выигрыш `even`).
**ActionsRow:** `[½]` 52×52 · `[CTA]` flex 1, h52 · `[2×]` 52×52.
CTA-тексты: `Выберите число` (неактивна) → `Ставка {N} на {X}` (белая) → `Ждём крупье… можно листать` (неактивна) → `Следующий раунд` (белая).

## 4. Игровая логика

```ts
type Phase = 'pick' | 'wait' | 'reveal' | 'done';
interface Round { phase: Phase; pick: number|null; stake: number; chip: number; item?: string|null; count: number; fx?: number; fy?: number }
state = {
  dealer: number,                 // индекс текущего крупье
  rounds: Record<number, Round>,  // раунд по каждому крупье (параллельная игра)
  stake: number, chip: number,
  mode: Record<number,'items'|null>,  // режим взаимности по крупье
  removed: Record<number,string[]>,   // снятые предметы по крупье
  item: string|null,
  offer: number|null,             // индекс крупье, для которого показать модалку взаимности
  full: boolean,                  // полноэкранное видео
  tour: { step: number; play: boolean; rect },
}
```
- Игрок всегда **ЧЁТ (место 0)**, крупье — **НЕЧЁТ (место 1)**. Победа игрока: `(pick + dealerPick) % 2 === 0`.
- Выигрыш: `stake*2 − ceil(stake*0.1)` (комиссия 10%).
- Подтверждение → `wait` → через 4.0 с `reveal` (открыть числа) → через 5.5 с `done`. Таймеры — на каждого крупье отдельно; переключение крупье не прерывает чужие раунды.
- При `done`: `count += 1`. Если `count === 3` и взаимность ещё не включена — `offer = dealer` (показать модалку).
- `½` — `max(1, floor(stake/2))`, `2×` — `min(balance, stake*2)`; выбор фишки = stake по номиналу. Менять ставку можно только в `pick`.
- При смене крупье ставка поднимается до его минимума (`dealer.min`).
- Caption: `ДЕЛАЙТЕ СТАВКИ` → `СТАВКИ СДЕЛАНЫ` → `{a} + {b} = {sum}` → `ПОБЕДА +{win}` | `{ИМЯ} ЗАБИРАЕТ` | `ПОБЕДА · {ПРЕДМЕТ} СНИМАЕТСЯ`.

### Крупье (mock)

Число крупье в демо: `(index*3+3) % 10`.

## 5. Режим «Крупье отвечает взаимностью»

**Разблокировка:** белое кольцо вокруг кружка заполняется за 3 сыгранных раунда с этим крупье.

**Модалка (offer):** затемнение `#05070DD9` + blur 8; снизу: аватар 128px с белым свечением (`0 0 0 4px #fff, 0 0 40px 10px #ffffff88`), капс «3 РАУНДА СЫГРАНО · КОЛЬЦО ЗАПОЛНЕНО», заголовок 28/800 «{Имя} отвечает взаимностью», текст «И даёт тебе возможность снять с неё аксессуар. Выбери предмет — под ним ставка, на которую она сыграет.», CTA «Выбрать, что снять», текстовая «Позже».

**ItemsBlock (вместо ChipsRow):**
1. Белый информер (radius 14, padding 10 12, 13px): «**{Имя}** отвечает взаимностью и даёт тебе возможность снять с неё».
2. Строка лейблов: `ЧТО СНЯТЬ? · СТАВКА ПОД ПРЕДМЕТОМ` (или `· СНЯТО n/7`) — справа `ТВОЯ СТАВКА {N}`.
3. Горизонтальный скролл кружков 46px: внутри эмодзи 22px, под кружком мини-фишка 9px + цена.
   | Предмет | Эмодзи | Ставка |
   |---|---|---|
   | Очки | 🕶️ | 5 |
   | Шляпа | 👒 | 5 |
   | Шарф | 🧣 | 10 |
   | Серьги | 💎 | 10 |
   | Перчатки | 🧤 | 15 |
   | Туфли | 👠 | 20 |
   | Пиджак | 🧥 | 25 |
   Выбран: фон `#FFF`, кольцо `#4F8BFF`, `translateY(-5px)` (у контейнера скролла верхний padding ≥ 9px, чтобы не обрезалось). Выбор предмета ставит `stake = цена`. Снятые — opacity .35, подпись «снято», недоступны.
- CTA: `Выберите предмет` → `{N} на {X} · против «{Предмет}»`.
- При победе предмет добавляется в `removed[dealer]`.
- Список — **только аксессуары и верхняя одежда**; других значений не предусмотрено (жёстко зашито на бэкенде).

## 6. Полноэкранное видео
Оверлей на весь экран: фон = видео крупье. Сверху: аватар 36px с кольцом, имя, `LIVE · {scene}`, таймер-пилюля, ✕. Снизу: caption, пилюля статуса ставки («Ставка не сделана» / «Выбрано X · не подтверждено» / «Твоя ставка N на X»), ряд `[🎙] [К игровому полю] [⚑]`. Закрытие — ✕ или CTA.

## 7. Онбординг

### 7.1 Экран правил (первый запуск)
Оверлей `linear-gradient(180deg,#0B123099,#05070DF2 45%)` + blur 10. Снизу: три кружка (центральный 96px с синим кольцом), заголовок 32/800 «Чёт или нечёт — один на один с крупье», 3 карточки-правила с номерами в синих кругах:
1. Ты и крупье тайно выбираете по числу 0–9
2. Числа складываются. **Чётная сумма** — выигрываешь ты
3. Победитель забирает обе ставки минус 10%
CTA «Смотреть видео-обучение · 36 сек», текстовая «Я знаю правила».

### 7.2 Видео-обучение (автоплей, 10 шагов × 3.6 с)
- Сверху (top 52): 10 сегментов-полосок (как сторис) — заполнение текущего `width 0→100%` за 3.6 с linear; под ними «ВИДЕО-ОБУЧЕНИЕ · n/10», кнопки «II/▶» и ✕.
- **Подсветка**: прямоугольник (или круг для кружка) поверх целевого элемента + 8px отступ: `box-shadow: 0 0 0 2px #FFF, 0 0 30px 8px #FFFFFFB3, 0 0 0 2000px #05070DD9`; перемещается между шагами `.45s cubic-bezier(.3,1.3,.5,1)`.
- **Выдвижение**: сам целевой элемент получает `transform: scale(k) translateY(-2px)` (k: таймер 1.15, полоса дуэли 1.04, поле 1.03, фишки 1.08, ½/2× 1.1, CTA 1.06, «?» 1.25, кружок 1.07), transition `.35s cubic-bezier(.3,1.4,.5,1)`.
- Карточка-подсказка — **белая** (radius 22, текст `ink`), над элементом, если он ниже середины экрана, иначе под ним; заголовок 18/800, текст 14, «Тап — дальше».
- Тап в любом месте — следующий шаг; пауза останавливает таймер; ✕ — завершить.
- Позиции подсветки **измерять из DOM** (`getBoundingClientRect` целевого `[data-tour=key]`) при каждом переходе шага — не хардкодить.

| # | data-tour | Заголовок | Текст |
|---|---|---|---|
| 1 | stage | Кружки — это крупье | Каждый кружок — живой крупье. Свайпай влево и вправо, чтобы сменить стол. |
| 2 | center | Тап — полный экран | Нажми на центральный кружок, и видео откроется на весь экран. |
| 3 | ring | Белое кольцо — путь к взаимности | Каждый раунд с крупье заполняет кольцо. Сыграй 3 раунда — и она ответит взаимностью. |
| 4 | timer | Таймер раунда | Столько секунд осталось, чтобы сделать ставку. |
| 5 | board | Выбери число | Зелёные — чётные, красные — нечётные. Сумма твоего числа и числа крупье решает исход. |
| 6 | chips | Фишки — это ставка | Выбери номинал. Выбранная фишка приподнимается. |
| 7 | half (+dbl, общая подсветка ряда) | ½ и 2× | Быстро уменьшить вдвое или удвоить ставку. |
| 8 | confirm | Сделай ставку | Кнопка белеет, когда число выбрано. Нажми — фишка перелетит на поле. |
| 9 | duel | Итог раунда | Здесь откроются оба числа и сумма. Чётная — победа твоя. |
| 10 | help | Пересмотреть обучение | Кнопка «?» всегда запустит это видео снова. |

Реализация таймера шагов — в обработчиках (start/next/pause) через `setState(…, cb)` + `requestAnimationFrame`, а не в эффекте рендера.

### 7.3 Экран с подписями (справка, 5b)
Тот же игровой экран, на каждом элементе белый номер-маркер 22px (`box-shadow: 0 0 0 3px #4F8BFF99, 0 0 14px #FFFFFFCC`), справа/внизу — легенда:
1 Кружки-крупье · 2 Тап по кружку (полный экран) · 3 Белое кольцо (прогресс до взаимности) · 4 Таймер · 5 Полоса дуэли · 6 Поле чисел · 7 Фишки (в режиме взаимности — предметы) · 8 ½ и 2× · 9 Кнопка ставки · 10 «?». Открывается из «?» → «Все кнопки».

### 7.4 Чек-лист «Первые шаги» (4b, лента)
Bottom sheet `#141A33` над экраном баланса. Кольцо 88px `accent/blue` «2/5», заголовок «Первые шаги», «Пять шагов до первого раунда». Пункты: ✓ Подтвердить возраст · ✓ Проверить камеру и микрофон · (3, синий, активный) Пройти обучение — 30 секунд · 4 Пополнить баланс — от 10 фишек · 5 Сыграть первый раунд. CTA «Пройти обучение · 30 сек».

## 8. Десктоп 1440×900 (4c)
Сетка `300px | 1fr`. Слева — сайдбар `#FFFFFF08` + blur: лого, табы «Ручная/Авто», поле суммы с ½/2×, фишки «Фишки · размер ставки», сводка (ставка на число / выигрыш), CTA, «Последние раунды» (8 квадратов 34px). Справа: сцена (flex 1) с каруселью кружков → DuelStrip 56px → лейбл «ТВОЁ ЧИСЛО · 0–9» → поле 180px (5×2, цифры 38px). Полный экран видео — оверлей на весь фрейм. Видео-обучение на десктопе — те же шаги, подсказка справа от элемента.

## 9. Приёмка
- [ ] Свайп/стрелки/тап листают крупье, занятые пропускаются; тап по центру открывает полный экран, свайп — нет.
- [ ] Ставки у нескольких крупье идут параллельно; бейджи ●/+N/−N на соседях.
- [ ] Фишка перелетает на число; число уходит в угол.
